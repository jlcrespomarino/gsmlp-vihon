# Contributing

Report reproducible problems with model name, environment versions, input shape, parameters, random_state and a minimal example. Do not include confidential datasets, credentials or personal information.

Install requirements-validation.txt and run python run_checks.py before proposing changes. Changes to equations, preprocessing or heuristic policies should include mathematical justification, regression tests and a history entry. Passing analytical-gradient checks does not establish optimizer performance or benchmark superiority.
